# hyday-capture

把你在外面看到的內容，整理成 hyday 風味的 Markdown，落進你本機的 hyday vault。自動化在整理，不在收集，收集靠你主動擷取

## v1 範圍一句話

一個 Chrome 擴充功能，一鍵擷取當前網頁，用可自訂模板加 BYOK AI 在本機整理成筆記，參考你既有標籤下標，再用 File System Access API 直接寫進你指定的資料夾
