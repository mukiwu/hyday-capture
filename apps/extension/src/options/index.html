hyday-capture 設定

輸出資料夾

選一個資料夾，擷取的筆記會寫進這裡，通常就是你的 hyday vault。之後每次擷取都會自動寫入， 瀏覽器詢問權限時請選每次都允許。

尚未選擇資料夾

提示：筆記不會寫進 .hyday、templates、assets， 也不會用日期當檔名，避免被 hyday 誤認成 journal。

模板

用 JSON 編輯你的模板組，第一個 trigger 命中的模板勝出，皆不中則用最上面那組。 body 與 property 的值可用 {{變數}}，例如 {{title}}、{{content}}、{{author}}、 {{published|date:"YYYY-MM-DD"}}、{{selectorHtml:.price|markdown}}。
